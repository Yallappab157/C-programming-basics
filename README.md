# C variables & data types:
   a variable is a named place in memory used to store a value
   And data type tells C what kind of value it is.....
     int(integer) : 1,2,5,3,9,67
     float(decimal) : 2.5,8.9,9.5
     char(letters) : 'a','A'
     double(more decimal) : 10.567884
     for example : int age=19;
                   here 19(value),age(variable), int(data types)
